# GitHub 付费墙绕过方法分析

## Top 5 付费墙绕过工具

### 1. everywall/ladder ⭐8730
- **原理**: 自托管代理服务，通过代理获取页面并修改HTML结构去除付费墙遮挡层
- **技术细节**: 
  - CORS头移除
  - HTML DOM修改（移除paywall overlay div）
  - 规则引擎支持自定义站点特定规则
- **优点**: 自托管可控、规则灵活、社区活跃
- **缺点**: 对JS动态渲染站点无效、需要额外部署代理
- **适用场景**: 静态HTML付费墙、新闻网站订阅内容

### 2. NMAC427/12ft ⭐34
- **原理**: Safari浏览器扩展，直接操作DOM移除付费墙覆盖层
- **技术细节**:
  - 注入JavaScript到页面上下文
  - 识别并移除常见的paywall CSS类（.paywall, .premium-overlay等）
  - 恢复被隐藏的DOM内容
- **优点**: 用户体验好、无需额外服务
- **缺点**: 仅限Safari浏览器、维护成本高、无法处理服务端渲染的付费墙
- **适用场景**: 单用户日常浏览、Chrome/Firefox可扩展为对应浏览器扩展

### 3. everywall/ladder-rules ⭐34
- **原理**: 为ladder代理提供站点特定的绕过规则集
- **技术细节**:
  - JSON/YAML格式的规则定义
  - 按域名匹配规则
  - 支持CSS选择器移除、DOM替换、内容恢复等操作
- **优点**: 针对性强、可定制、易于分享
- **缺点**: 需持续维护规则库、新付费墙策略出现时需更新
- **适用场景**: 特定目标网站的批量爬取

### 4. Archive.org / Wayback Machine
- **原理**: 获取网站付费墙启用前的缓存版本
- **技术细节**:
  - 查询Wayback Machine API获取历史快照
  - 下载存档的HTML/PDF内容
- **优点**: 合法合规、无需破解付费墙
- **缺点**: 只能获取历史版本、无法获取实时内容
- **适用场景**: 已发布内容的归档、论文研究

### 5. Academic Key / Sci-Hub
- **原理**: 利用机构订阅权限或元数据索引提供论文全文
- **技术细节**:
  - DOI解析和重定向
  - 机构认证代理
  - PDF全文抓取
- **优点**: 合法合规（在合理使用范围内）、资源丰富
- **缺点**: 仅限学术内容、法律灰色地带
- **适用场景**: 学术论文下载、研究资料收集

## 技术分类

| 类别 | 代表工具 | 核心思路 |
|------|----------|----------|
| 代理修改 | Ladder | 通过代理获取原始HTML并修改DOM |
| 浏览器扩展 | 12ft | 客户端注入JS操作DOM |
| 规则引擎 | ladder-rules | 按站点配置绕过规则 |
| 缓存查询 | Archive.org | 获取历史版本而非实时内容 |
| 学术数据库 | Sci-Hub | 利用已有订阅权限 |

## 实施建议

1. **优先实现代理模式**：最通用，可绕过大部分静态付费墙
2. **添加DOM修改引擎**：处理客户端渲染的付费墙覆盖层
3. **多策略自动切换**：根据目标网站特征选择最佳绕过策略
4. **API拦截与模拟**：分析前端JS如何调用后端API获取付费内容
5. **Cookie/Session管理**：集成浏览器指纹技术维持有效登录状态
